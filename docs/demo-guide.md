# 시연 순서

모든 사업장과 원장은 합성 데이터다. `python server.py`로 실행한다.

1. 데이터 검수에서 6건 중 5건이 보류됨을 확인한다. 중복된 S001/S004는 둘 다 부분합에서 제외된다.
2. 근거 안내에서 `How should I handle missing energy readings?`를 English로 검색한다. 모델 서비스가 실행 중이면 `근거 검색 + AI 초안`으로 실제 생성한다. 문서 ID·rev2.0·인용·SHA를 확인한다.
3. 데이터 검수에서 S004를 연다. 합성 원장에는 SYN-KR-001의 중복으로 표시되어 있다. `중복 제출 등 집계 제외`를 체크하고 사유를 입력한다.
4. S003의 합성 원장 `9500 kWh`를 대조해 입력한다. S005는 `0.7 MWh`, S006은 `10 MWh / 2026-09`로 수정한다. 원자료를 보지 않고 단위나 부호를 자동 추정하는 과정이 아니다.
5. 검수 통과5·제외1·합46,200kWh를 확인한다. 담당자 확인 전에는 CSV가 차단된다.
6. 확인·인계에서 시연용 담당자·메모를 입력하고 `현재 버전 확인`을 누른다. 변경 기록·데이터/문서 해시와 확인 완료를 확인한다. CSV는 유효5행이다.
7. 확인 이후 S001을 수정한다. `데이터 변경 · 재확인 필요`로 바뀌고 CSV가 차단된다.

오래된 화면 재현: 두 탭에서 같은 상태를 연 뒤 한 탭에서 값을 고치고, 다른 탭에서 확인한다. 후자의 확인은409로 거절된다. 새 상태를 읽고 다시 검토해야 한다.
