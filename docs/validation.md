# 확인 범위

2026-10-06 Windows / Python3.13 로컬 실행. 기본 서버·테스트는 표준 라이브러리, 모델은 torch2.6.0+cpu / transformers4.49.0를 사용했다. 모델은 CPU 4threads / bfloat16 / greedy / max_new_tokens240이며, 가중치SHA를 고정한다.

## 결정적 경로

28개 unittest가 통과했다. 주요 불변식은 누락≠0, 중복 전체 보류, Decimal 단위 변환, 숫자 지수·범위·정밀도 제한, 현재 SOP만 검색, 정확한 인용, 데이터·문서 변경 시 확인 만료, 오래된 클라이언트 스냅샷 거절, 재연결 후SQLite 보존, 미확인CSV차단이다.

`scripts/verify_workflow.py`는 임시DB에서 409→409→200→409 내보내기 상태와5행46,200kWh를 재현한다. UI의 합성 원장 대조와 수정·확인·CSV다운로드도 별도 실행한다.

HTTP는 루프백 바인딩, Host/Origin/Sec-Fetch-Site 검사, 요청 크기 제한, static 경로 제한, 변수 SQL을 사용한다. 로컬 시연 경계이며 제품 보안 인증이나 공격 전수 검증을 뜻하지 않는다.

## 실제 모델 경로

`docs/model-evaluation/01`과`02`는 실제0.5B의 형식·필드 오류다. 실패를 보류한 화면도 보존했다. 이후1.5B에서 실행한 원출력·리비전·인용·시간은 같은 디렉터리의03이후 기록으로 확인한다. 프롬프트와 모델 선택에 사용한 개발 사례이며, 별도 보류 평가집의 정확도가 아니다.

인용 검사는 모델이 제시한 문서ID와 인용 문자열이 검색한 현행 문단과 정확히 같은지 검사한다. 문서의 개정번호와 원문 해시는 서버가 붙인다. 초안 전체가 그 문단에서 논리적으로 따라오는지, 답변이 질문을 충분히 해결하는지, 번역이 정확한지는 자동 보증하지 않는다.

실제 모델 실행이 없으면 UI가`retrieval-only`또는`generation-unavailable`로 표시한다. 모델 출력이 형식/인용 검사에서 탈락하면`generation-rejected`이며 데이터를 자동 변경하지 않는다.
